## Orchestrate

A standing project in one coordinator chat. Multi-day. Many stacked PRs. Dozens to hundreds of subagents.

**Incorrect:** Route here because the phrasing sounds like a program. The coordinator edits code. Workers rebase or run `gt`.

**Correct:** You own the program, never the code. Author briefs. Drain the queue. Keep the frontier green. Decide.

Three rules carry the rest:

- Completions are queue events, not interrupts.
- Every spawn and every resume carries the standing orders verbatim.
- The brief is the product. A vague brief fails quietly.

If one agent could finish inside the session budget, stop and run `run-autonomous`.
