## Feature

New or changed behavior from a named data shape.

**Incorrect:** Implement in the lead chat. Skip `how` and `architect`. Ship a throwaway sketch.

**Correct:** You own the design. `how` → `architect` → four-item throughput checkpoint → delegate the diff → verify on the matching surface → Opening a PR.

1. `how` over the affected subsystem.
2. `architect`. A skip stays as `architect skipped: <reason>`.
3. Throughput checkpoint: blocking first steps, independent workstreams, shared mutable state, smallest safe decomposition.
4. Delegate with the named data shape. Arena when several shapes are valid. Review the diff yourself.
5. Verify on the matching surface.
6. Rebase into small ordered commits.
7. `interrogate` if the design is contested.
8. Opening a PR.

Library: `ai/playbooks/feature.md` (dest: `playbooks/feature.md`).

Notes: A migration across many call sites is figure-it-out. A sketch to decide is `build-prototype`. Structure only is `build-refactoring`.
