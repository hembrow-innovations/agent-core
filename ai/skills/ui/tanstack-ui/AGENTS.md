# TanStack UI reference

Reference only. Prefer `SKILL.md` stack notes and `rules/<id>.md`.

This pack replaces `frontend-design` and `vercel-react-best-practices` for TypeScript monorepos on TanStack Start, React, Tailwind CSS v4, and CVA.

Do not load this file unless you are stuck and the router plus two or three rules were not enough.

- Start, tokens, CVA, bundle, and server rules are adapted for this stack.
- Re-render, rendering, JS, and advanced rules are stack-agnostic React.
- Query key factories and domain mutations live in **tanstack-query**.
- Face load lives in **typography**.
- Type-system rules live in **typescript-best-practices**.

The original Vercel essay (Next, RSC, SWR) is in `../vercel-react-best-practices/AGENTS.md`. Do not apply Next APIs from it.
