# agent-core

Skill and profile pack for OpenCode, Claude, Pi, and agents.

## Develop this repo with Pi

```
pnpm exec agentic-core install . --profile agentic-core
pi
```

Trust the folder, then `/draconic-mode`.

Edit `ai/skills/`, `ai/playbooks/`, `ai/pi/`, and `profiles/`. `.pi/` is a generated dest.
