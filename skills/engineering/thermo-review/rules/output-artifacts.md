## Review artifacts

Create two working reports:

1. An HTML file for ease of reading
2. A Markdown file

Place them through **management**. Working reports belong in the local logs tree, not in `docs/`. If `AGENTS.md` or `WORKSPACE.md` already names a tracker (`.scratch/`, `docs/planning/`, GitHub Issues), that file wins. Do not write process scratch into tracked product paths unless asked.
